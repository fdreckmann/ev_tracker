## Empfehlungen für Screenshots

- **Auflösung:** mind. 1280×800px, idealerweise 1440×900px
- **Format:** PNG (lossless)
- **Theme:** Dark Mode (wie Standard in der App)
- **Sprache:** Deutsch
- **Keine echten Zugangsdaten** in Screenshots — Testdaten verwenden
- **Keine echten Kennzeichen oder Namen** — anonymisieren

## Screenshots erstellen

1. EV Tracker lokal starten (Docker oder direkt via `python app/server.py`)
2. Mit Testdaten befüllen (oder einen Snapshot der eigenen Instanz nutzen)
3. Screenshots in diesem Verzeichnis ablegen
4. Commit und Push
